      <div class="govspeak"><h2 id="about-this-data">About this data</h2>

<p>These files provide detailed data for road collisions in Great Britain from 1979, and the vehicles and casualties involved. The statistics relate only to personal injury collisions on public roads that are reported to the police, and subsequently recorded, using the STATS19 <a href="https://www.gov.uk/guidance/road-accident-and-safety-statistics-guidance#data-collection">collision reporting system</a>.</p>

<p>Final annual data is released annually in late July (brought forward from September) following the publication of the final annual reported road casualties Great Britain statistical publication. In addition, unvalidated provisional mid-year data (covering January to June) is released at the end November, to provide more up to date information.</p>

<p>This data contains all the non-sensitive fields that can be made public. Sensitive data fields, for example contributory factors data, can be requested by completing the <a href="https://www.gov.uk/guidance/road-accident-and-safety-statistics-guidance#data-protection-and-privacy">sensitive data form</a> and contacting the road safety statistics team at <a href="mailto:roadacc.stats@dft.gov.uk">roadacc.stats@dft.gov.uk</a>.</p>

<p>The <a rel="external" href="https://cran.r-project.org/package=stats19">STATS19 R package</a> developed independently of DfT, offers an alternative way to access this data for those familiar with the R language.</p>

<h2 id="guidance-documentation">Guidance and documentation</h2>

<p>The data files are provided in a coded format rather than containing textual strings. The data guide below allows users to decode these values.  It also provides a mapping between variables which have changed following the migration to a new data specification.</p>

<p><span class="gem-c-attachment-link">
  <a class="govuk-link" href="https://assets.publishing.service.gov.uk/media/6ab2a71d997a4b2950cced58/dft-road-casualty-statistics-road-safety-open-dataset-data-guide-2025.xlsx">Open dataset data guide</a>  (<span class="gem-c-attachment-link__attribute">MS Excel Spreadsheet</span>, <span class="gem-c-attachment-link__attribute">83.1 KB</span>)</span></p>

<p>The introduction of injury-based reporting of casualty severity for some police forces appears to have led to a change in the reported severity of road casualties. Users are recommended to review the <a href="https://www.gov.uk/government/publications/guide-to-severity-adjustments-for-reported-road-casualty-statistics">severity adjustment guide</a> for information on how the adjustment figures are calculated and the guide below for information on how these are applied in the open data.  Prior to 2024, the severity adjustment figures were provided as separate files, but they are now provided as variables within the main data tables.</p>

<p><span class="gem-c-attachment-link">
  <a class="govuk-link" href="https://assets.publishing.service.gov.uk/media/691c644021ef5aaa6543eef0/dft-road-casualty-statistics-severity-adjustment-figure-guidance.docx">Road safety open data - severity adjustment guidance</a>  (<span class="gem-c-attachment-link__attribute">MS Word Document</span>, <span class="gem-c-attachment-link__attribute">17.7 KB</span>)</span></p>

<h2 id="changes-and-revisions">Changes and revisions</h2>

<p>Except for the severity adjustments, data are not routinely revised though occasionally minor amendments to previous years can be made. The following guide contains details of historic changes to the specification of the data published on road casualties:</p>

<p><span class="gem-c-attachment-link">
  <a class="govuk-link" href="https://assets.publishing.service.gov.uk/media/691c6440e39a085bda43eed7/Understanding-historical-road-safety-data.docx">Understanding historical road safety data</a>  (<span class="gem-c-attachment-link__attribute">MS Word Document</span>, <span class="gem-c-attachment-link__attribute">20.1 KB</span>)</span></p>

<p>Revisions to the open data published in previous years can be found in:</p>

<p><span class="gem-c-attachment-link">
  <a class="govuk-link" href="https://assets.publishing.service.gov.uk/media/6a6391812dc18ebe4c3b2bca/dft-road-casualty-statistics-historical-revisions-data.csv">Historical revisions data</a>  (<span class="gem-c-attachment-link__attribute"><abbr title="Comma-separated Values" class="gem-c-attachment-link__abbr">CSV</abbr></span>, <span class="gem-c-attachment-link__attribute">70.2 KB</span>)</span></p>

<div class="call-to-action">
  <h3 id="revisions">Revisions</h3>

  <p><strong>September 2026:</strong> The coding of vehicle type (within the vehicles extract) and road user type (within the casualty extract) has been improved to separately identify ‘powered personal transporters’ (including e-scooters) which were previously included within the ‘other’ category.  An additional flag to identify e-scooter casualties has been added to the casualty data extract.</p>

  <p><strong>July 2026:</strong> Issues with the vehicle_location_restricted_lane variable, previously identified in November 2025, which affected data files were first published in September 2025, have now been fixed where this is possible. “Lay-by or hard shoulder” was incorrectly recoded as “no data” in 2024. Details of the collisions exact records which have been updated can be found in the historical revisions log.</p>

  <p><strong>November 2025:</strong> The data files were first published in September 2025 contained an error in the junction_detail variable that caused collisions recorded as “other junction” to be incorrectly listed as “no data”. This was corrected in the later versions of these files (published November 2025 onwards).</p>
</div>
