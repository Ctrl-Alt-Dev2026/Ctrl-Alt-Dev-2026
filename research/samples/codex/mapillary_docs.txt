See the <b>Token Exchange</b> endpoint.</li></ol><h3>Authorization</h3><p>Endpoint: <b>GET https://www.mapillary.com/connect</b></p><p>URL Parameters:</p><ol><li><b>client_id - int</b>: Your app&#039;s client ID</li><li><b>redirect_uri - string (optional)</b>: Must be same as the callback URL of your app</li><li><b>response_type - string (optional)</b>: Must be &quot;code&quot;</li><li><b>scope - string (optional)</b>: Scope of the authorization. There are 3 possible scopes: read, write, or upload. The parameter must be subset of your app&#039;s scopes.</li><li><b>state - string (optional)</b>: An arbitrary string that will be redirected back to your app</li></ol><p>Responses:</p><p>When successful, the user’s browser is redirected back to the app&#039;s configured callback URL with the following query parameters:</p><ol><li><b>code - string</b>: The authorization code. Possible error codes:<ol><li>user_denied: The user denied the authorization</li><li>invalid_request: User session is invalid or expired</li><li>invalid_scope: The requested scopes is out of the app&#039;s scopes</li><li>server_error: Internal error</li></ol></li><li><b>state - string (optional)</b>: The state value passed from the authorization URL</li></ol><p>Examples:</p><p>Assume your app&#039;s callback URL is &quot;https://yourapp.com/callback&quot;.         &#125;
      ]
  &#125;
  </code></pre><h3>Download map features</h3><p>You can download points and traffic signs from the <a href="/app" class="_ad6a _ad6c">Mapillary website</a>. The data is in the GeoJSON format. </p><p>To download data, zoom in on the map to the location you’re interested in and turn on the map data (points or traffic signs). Press the “Download” button to download all visible points or traffic signs in a JSON file.</p><h2 id="detection">Detection <a href="#detection" class="_ad6a _ad6c">#</a></h2><p>Represent an object detected in a single image. For convenience this version of the API serves detections as collections. They can be requested as a collection on the resource (e.g. image or map feature) they contribute or belong to.</p><h3>Endpoints</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>https://graph.mapillary.com/:image_id/detections - detections in the image with ID image_id</li><li>https://graph.mapillary.com/:map_feature_id/detections - detections contributing to the map feature with ID map_feature_id</li><li>https://graph.mapillary.com/images?fields=detections.id,detections.value - search image detections</li></ul><h3>Fields</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>id - string, the detection ID.</li><li>created_at - string, ISO 8601 timestamp of when the detection was created (e.g. &quot;2022-01-22T12:23:42+0000&quot;).</li><li>geometry - string, base64 encoded polygon.</li><li>image - object, image the detection belongs to.</li><li>value - string, what kind of object the detection represents.</li></ul><p>Sample detection request:</p><pre class="_amhu"><code>
  GET https://graph.mapillary.com/$IMAGE_ID/detections?access_token=$TOKEN&amp;fields=image,value,geometry

  &#123;
    &quot;image&quot;: &#123;
			&quot;id&quot;: &quot;$IMAGE_ID&quot;
      &quot;geometry&quot;: &#123;
        &quot;type&quot;: &quot;Point&quot;,
        &quot;coordinates&quot;: [0, 0]
    &#125;,
    &quot;id&quot;: &quot;$DETECTION_ID&quot;
    &#125;,
    &quot;value&quot;: &quot;information--highway-interchange--g1&quot;,
    &quot;geometry&quot;: &quot;GjgKBm1weS1vchIYEgIAABgDIhAJnC3uFxroAwAA7AbnAwAPGgR0eXBlIgkKB3BvbHlnb24ogCB4AQ==&quot;
  &#125;
  </code></pre><h3>Segmentation</h3><p>The geometry field of a detection contains the segmentation data for each detection, but it must be decoded in order to get normalized coordinates for use with MapillaryJS or any image.</p><p><b>Sample decoding</b></p><p>In Python, segmentation can be decoded according to the following example: </p><pre class="_amhu"><code>
  import base64
  import mapbox_vector_tile

  base64_string = &quot;GjgKBm1weS1vchIYEgIAABgDIhAJnC3uFxroAwAA7AbnAwAPGgR0eXBlIgkKB3BvbHlnb24ogCB4AQ==&quot;

  decoded_data = base64.decodebytes(base64_string.encode(&#039;utf-8&#039;))

  detection_geometry = mapbox_vector_tile.decode(decoded_data)

  print(detection_geometry) </code></pre><p>The output of the decoding will not be normalized, but gives a series of coordinates:</p><pre class="_amhu"><code>
  detection_geometry = &#123;&#039;mpy-or&#039;: &#123;&#039;extent&#039;: 4096, &#039;version&#039;: 2, &#039;features&#039;: [&#123;&#039;geometry&#039;: &#123;&#039;type&#039;: &#039;Polygon&#039;, &#039;coordinates&#039;: [[[2402, 2776], [2408, 2776], [2413, 2762], [2413, 2746], [2409, 2736], [2404, 2732], [2363, 2734], [2357, 2747], [2359, 2771], [2363, 2776], [2377, 2779], [2383, 2789], [2389, 2788], [2392, 2783], [2396, 2783], [2402, 2776]]]&#125;, &#039;properties&#039;: &#123;&#125;, &#039;id&#039;: 1, &#039;type&#039;: 3&#125;]&#125;&#125;
  </code></pre><p>To normalize this, divide each x and y coordinate by the extent (4096). To get exact pixel coordinates, multiply the normalized x by the width of the image containing the detection, and the normalized y coordinate by the height, remembering that pixel coordinates start at the top left corner of the image when visualized. Retrieve the height and width by making an API request for the image key with the height and width fields.</p><h3>Detection search</h3><p>Detections are searchable through the <b>graph.mapillary.com/images</b> endpoint and specifying fields (prefixed with &quot;deltections&quot;) as stated above in addition to a filter, e.g. bounding box. Note that filters are applied to images.</p><blockquote style="border: 1px solid silver; padding: 0.5em;"><b>Note</b>: Querying detection data with the <b>bbox</b> parameter is suitable for relatively small area (must be smaller than 0.01 degrees square). If you&#039;re planning on querying and downloading data for larger areas, please use <a href="https://github.com/mapillary/mapillary-python-sdk" target="_blank" style="font-size:12px; color:#05cb63" data-lnfb-mode="ie">mapillary-python-sdk</a> which is optimized for that use case.</blockquote><p>Query detections and images in a bounding box:</p><pre class="_amhu"><code>
  GET https://graph.mapillary.com/images?fields=captured_at,detections.id,detections.value&amp;access_token=$TOKEN&amp;limit=10&amp;bbox=12.967,55.597,13.008,55.607

&#123;
  &quot;data&quot;: [
    &#123;
      &quot;captured_at&quot;: 1583494424000,
      &quot;detections&quot;: &#123;
        &quot;data&quot;: [
          &#123;
            &quot;id&quot;: &quot;$DETECTION_ID1&quot;,
            &quot;value&quot;: &quot;object--sign--store&quot;
          &#125;,
          &#123;
            &quot;id&quot;: &quot;$DETECTION_ID2&quot;,
            &quot;value&quot;: &quot;marking--discrete--other-marking&quot;
          &#125;
        ]
      &#125;,
      &quot;id&quot;: &quot;$IMAGE_ID&quot;
    &#125;,
    &#123;
      &quot;captured_at&quot;: 1413500205000,
      &quot;id&quot;: &quot;$IMAGE_ID2&quot;
    &#125;
  ]
&#125;
  </code></pre><h2 id="organization">Organization <a href="#organization" class="_ad6a _ad6c">#</a></h2><p>Represents an organization which can own the imagery if users upload to it.</p><h3>Endpoints</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>https://graph.mapillary.com/:organization_id</li></ul><h3>Fields</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>id - string, the organization ID.</li><li>slug - short name, used in URLs.</li><li>name - nice name.</li><li>description - public description of the organization.</li></ul><p>Sample organization request:</p><pre class="_amhu"><code>GET https://graph.mapillary.com/$ORGANIZATION_ID?access_token=$TOKEN&amp;fields=name

  &#123;
    &quot;id&quot;: &quot;$ORGANIZATION_ID&quot;
    &quot;name&quot;: &quot;My Organization&quot;
  &#125;
  </code></pre><h2 id="sequence">Sequence <a href="#sequence" class="_ad6a _ad6c">#</a></h2><p>Represents a sequence of Image IDs ordered by capture time.</p><h3>Endpoints</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>https://graph.mapillary.com/image_ids?sequence_id=XXX</li></ul><h3>Response shape</h3><p>The endpoint returns a collection of objects each containing only the image <b>id</b> field:</p><pre class="_amhu"><code>
  GET https://graph.mapillary.com/image_ids?access_token=$TOKEN&amp;sequence_id=$SEQUENCE_ID

  &#123;
    &quot;data&quot;: [
      &#123; &quot;id&quot;: &quot;$IMAGE_ID_1&quot; &#125;,
      &#123; &quot;id&quot;: &quot;$IMAGE_ID_2&quot; &#125;,
      ...
    ]
  &#125;
  </code></pre><p>Note: The <b>fields</b> query parameter is not honored by this endpoint.</p><h2 id="multiple-entities">Multiple Entities <a href="https://www.mapillary.com/developer/api-documentation#multiple-entities" class="_ad6a _ad6c">#</a></h2><p>Returns multiple entities based on their IDs.</p><h3>Endpoints</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>https://graph.mapillary.com?ids=ID1,ID2,ID3</li></ul><h3>Parameters</h3><ul class="_90f8" style="margin-bottom: 24px;"><li>ids - A list of entity IDs separated by comma. The provided IDs must be in the same type (e.g. all image IDs, or all detection IDs)</li></ul><h2 id="rate-limits">Rate limits <a href="#rate-limits" class="_ad6a _ad6c">#</a></h2><p>There are 3 tiers of rate limits applied to different APIs/tile endpoints:</p><ol><li>Requests to entity APIs, e.g. <b>graph.mapillary.com/:image_id</b>, are limited to 60,000 per minute per app.</li><li>Requests to search APIs, e.g. <b>graph.mapillary.com/images?bbox=minx,miny,maxx,maxy</b>, are limited to 10,000 per minute per app.</li><li>Requests to <b>tiles.mapillary.com</b> are limited to 50,000 per day (not per minute).</li></ol><p> Exceeding the <b>Graph API rate limit</b> your app will be throttled and users will receive &quot;Application request limit reached&quot; error. Here is a response example:</p><pre class="_amhu"><code>&#123;&quot;error&quot;:&#123;&quot;message&quot;:&quot;Application request limit reached&quot;,&quot;type&quot;:&quot;OAuthException&quot;,&quot;is_transient&quot;:true,&quot;code&quot;:4,&quot;error_subcode&quot;:1349210,&quot;error_user_title&quot;:&quot;Rate Limit Exceeded&quot;,&quot;error_user_msg&quot;:&quot;You are hitting rate-limits on the node that you are attempting to fetch. Please wait and try again later.&quot;,&quot;fbtrace_id&quot;:&quot;A-ZiBnH0_13Dq2KIXeAkenU&quot;&#125;&#125;

  </code></pre><p>Exceeding the <b>Tile API rate limit</b> your app will get status code 4xx.</p><h2 id="embed">Embed images <a href="#embed" class="_ad6a _ad6c">#</a></h2><p>Add Mapillary images to a web site or app with the Mapillary embed in an iframe.</p><p>The iframe tag below would show a 640x480px image with ID 550092599700936. </p><pre class="_amhu"><code> &lt;iframe
    src=&quot;https://www.mapillary.com/embed?image_key=550092599700936&amp;style=photo&quot;
    height=&quot;480&quot;
    width=&quot;640&quot;
    frameborder=&quot;0&quot;&gt;
 &lt;/iframe&gt;</code></pre><p>The URL has the following format:</p><pre class="_amhu"><code>https://www.mapillary.com/embed?image_key=IMAGE_ID&amp;style=STYLE</code></pre><p>Parameters:</p><ul class="_90f8" style="margin-bottom: 24px;"><li><b>image_key</b> (required) - Mapillary image ID</li><li><b>style</b> (optional) - determines the layout of the embed. Options are <b>photo</b> (only the image viewer is visible), <b>split</b> (image and map are visible, equal size) or <b>classic</b> (image and map are shown and visible, user can switch focus between map and image)</li></ul><h2 id="glossary">Glossary <a href="#glossary" class="_ad6a _ad6c">#</a></h2><h3>Client access token</h3><p>Is a token required for all API calls, whether they&#039;re Entity API calls or vector tile requests. This token identifies the application used for generating it and enables making request on behalf of it. If a hacker steals it, they would be able to make a request on behalf of your application! </p><h3>User access token</h3><p>Is a token obtained by the user when authentication through the OAuth2 flow. It authenticates both the user and the application it used. It is preferred to send user tokens as the authorization header (see Authentication section). This token is equivalent to a user password, if a hacker steals it, they&#039;ll be able to call API on behalf of the user.</p></div></div></section></div><div style="width: 320px"><div
