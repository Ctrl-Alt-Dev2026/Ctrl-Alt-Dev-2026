3. Publică o versiune verificată

Publicarea este o decizie separată. Selectează evenimentele canonice și asociază-le explicit la infrastructura din contextul {{ session.dataMode() }}. Minimum două evenimente la o locație sunt necesare pentru scor; un singur eveniment poate avea dosar fără rang.

O publicație nouă conține exact selecția de mai jos, nu adaugă automat evenimente peste versiunea precedentă. Clasamentul se calculează în backend și rămâne fix în versiunea publicată.
